This project develops a scalable machine learning workflow for stress detection using the WESAD dataset. Apache Spark supports distributed data processing, preprocessing, and pipeline storage management. Multiple classification models, including Random Forest, Logistic Regression, Gradient-Boosted Trees, and Multilayer Perceptron, are evaluated using ROC-AUC, weighted F1-score, and accuracy. Feature importance analysis identifies influential predictors, while confusion matrices and prediction stability experiments assess model behaviour. Tableau dashboards present data quality, class distribution, participant-level stress patterns, model performance, scalability benchmarks, and storage requirements. The project combines predictive modelling, distributed processing, and visual analytics to support systematic evaluation of stress-detection approaches.
